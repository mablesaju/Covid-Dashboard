# COVID-19 Data Analysis Dashboard

## Overview

This project is an interactive **COVID-19 dashboard built using Microsoft Power BI**. It presents COVID-19 statistics through different views, allowing the data to be explored by continent, country, and India.

## Dashboard Views

- **Summary Data** – Provides an overall view of confirmed, recovered, active, and death cases along with trends over time.
- **Continent Analysis** – Compares COVID-19 statistics across different continents using charts and tables.
- **Country Analysis** – Provides country-level comparisons of COVID-19 figures and related rates.
- **India Analysis** – Displays COVID-19 statistics and trends specifically for India.

## Key Features

- KPI cards for confirmed, recovered, active, and death cases
- COVID-19 trends over time
- Country-wise and continent-wise analysis
- Interactive navigation between dashboard pages
- Filters and slicers for exploring the data
- Map-based visualization of COVID-19 data
- Tables for comparing COVID-19 rates across countries
- Charts showing recovered, active, and death cases

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Excel / CSV

## Objective

The objective of this mini-project is to analyze COVID-19 data and present meaningful information through an interactive Power BI dashboard. The visualizations make it easier to compare regions, examine trends, and understand the overall impact of COVID-19.
