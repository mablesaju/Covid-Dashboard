# COVID-19 Data Analysis Dashboard

## Overview

This project is an interactive **COVID-19 dashboard created using Microsoft Power BI**. It presents COVID-19 statistics through different dashboard views, including continent, country, and India-level analysis.

## Dashboard Views

- **Summary Data** – Displays overall confirmed, recovered, active, and death cases along with COVID-19 trends over time.
- **Continent Analysis** – Provides a comparison of COVID-19 statistics across different continents.
- **Country Analysis** – Shows country-wise COVID-19 statistics and related rates.
- **India Analysis** – Focuses on COVID-19 statistics and trends for India.

## Key Features

- KPI cards for COVID-19 statistics
- Trend analysis over time
- Country-wise and continent-wise comparisons
- Interactive filters and slicers
- Map-based visualization
- Tables for comparing COVID-19 rates
- Charts for recovered, active, and death cases
- Interactive navigation between dashboard views

## Tools Used

- Microsoft Power BI
- Power Query
- Excel / CSV

## Objective

The objective of this mini-project is to analyze COVID-19 data and present it through an interactive dashboard. The visualizations make it easier to compare regions, explore statistics, and identify trends in the data.
